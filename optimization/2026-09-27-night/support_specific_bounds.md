# A sharper check of the corrected support condition

This computation examines every pair of skills in each original32-task full
dictionary, not just pairs chosen after seeing their bound. It concerns the
weighted support-specific theta_S in the corrected KKT theorem.

For an inactive block j and support S={s1,s2}, split

    [M1 M2] = q_j^{-1} U_j^T A_S (A_S^T A_S)^{-1} W_S.

The required supremum is over ||v1||,||v2||<=1. Its dual form is

    max_{||u||=1} (||M1^T u|| + ||M2^T u||).

Each evaluated unit vector supplies a lower bound. For any t in (0,1), weighted
Cauchy-Schwarz gives the upper bound

    sqrt(lambda_max(M1 M1^T/t + M2 M2^T/(1-t))).

Taking the minimum of several valid upper bounds remains an upper bound. Scalar
optimization tightens this expression without assuming that the optimizer finds
the exact supremum. The maximum over inactive blocks bounds theta_S. The script
records both bounds, the restricted Gram's minimum eigenvalue, all496 supports,
the manually specified Compound constituents, and a numerical margin of1e-6.

This is a numerical check of a sufficient geometric condition. Even a bound
below one would still require the theorem's generative representation, noise,
lambda and signal-strength assumptions before claiming support recovery for an
observed task. A lower bound above one rejects this uniform irrepresentability
condition for that support, not the possibility of recovering particular signals.

## Completed numerical check

All496 pairs were checked in each original full dictionary. The number whose
computed upper bound, plus the1e-6 numerical margin, is below one is:

| Dictionary | Two-block sets satisfying the geometric bound | Benchmark Compound constituent sets among them |
|---|---:|---:|
| Llama-3.1-8B | 10 | 0 |
| Llama-3.2-3B | 1 | 0 |
| Gemma-2-2B | 1 | 1 |
| Qwen3-4B | 2 | 0 |
| Qwen2.5-3B | 0 | 0 |

For example, Llama-3.1's park-country/word-length pair has an upper bound
0.9417937318 before the margin, and restricted Gram minimum eigenvalue0.6363702.
Gemma-2's country-capital/word-length pair has an upper bound0.9978110662.
The latter identifies a geometric support condition only; the corresponding
semantic task need not be generated by a two-block linear representation with
the required noise and signal strength.

Every one of the14 eligible pairs was also checked with three independently
drawn planted coefficient/noise instances. The bounded noise norm was1e-5;
lambda used twice the conservative noise threshold, and every unit-norm true
block exceeded the theorem's coefficient-error bound. All42 instances recovered
the exact planted support and obeyed that bound. These checks use the full
weighted objective at the prescribed lambda, not the deployment support-capped
lambda-selection path. See `support_specific_recovery_checks.json` for all
values and hashes of the input bound files.
